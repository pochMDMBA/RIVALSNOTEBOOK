# RIVALSNOTEBOOK V13.3 Release Notes

## Role-based recommendation columns

- Counterpicker recommendations are now displayed in three dedicated columns: Vanguard, Duelist and Support.
- Each Counterpicker role column is independently sorted from highest to lowest points. The existing matchup score, tier weights, community votes, reason details and expand/collapse controls are preserved.
- Synergy recommendations use the same three-column layout, including the Official In-Game Team-Ups list.
- Synergy pairs are grouped by the role of the suggested teammate. When a flexible Multi-role hero is suggested, the pair follows the selected ally's role; if the pair is already fully selected, the first ally's role is used for display.
- Deadpool's existing Multi-role data and in-card role label are unchanged. In Counterpicker's three-column layout, a standalone Multi-role counter suggestion uses Duelist as its display fallback so no fourth column is introduced.

## Workspace sizing

- Reduced the hero-roster panel width and expanded the recommendation panel on both Counterpicker and Synergies.
- Kept the two workspaces geometrically consistent and retained the existing stacked layout at tablet/mobile breakpoints.
- Added compact card and portrait sizing within the three role columns so matchup details and synergy pairings remain usable.

## Preserved functionality

- Existing score calculations, point totals, upvotes, counter reason editing, group-derived recommendations, combo editing, official Team-Up classification and collapse controls are retained.
- Supabase schema/configuration, Vercel configuration, map assets and tactical-board behavior are unchanged from V13.2.
