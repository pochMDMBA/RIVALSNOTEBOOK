# RIVALSNOTEBOOK V13.5 Release Notes

## Counter and Synergy entry polish

- Rewrote generic contrastive endings in built-in counter and synergy descriptions into direct, actionable matchup guidance.
- Added player-submitted counters covering Groot into Peni, Peni into Hulk, Phoenix into key ultimate/structure matchups, Ultron and Jeff into Elsa, Magneto and Hulk into Jeff, Loki into Psylocke, Namor/Peni defensive interactions, Punisher crowd-control immunity, Jeff into Invisible Woman, Hulk anti-dive matchups, Iron Fist peel matchups, Squirrel Girl into Peni, and Emma Frost into Adam Warlock.
- Updated existing Hulk/Spider-Man, Hulk/Venom, Punisher/Namor and Thor/Angela records with the supplied matchup detail.
- New records are labelled as player-submitted mechanics tips and carry no invented source URLs or votes.
- Added a text migration for built-in entries: a saved entry is updated only when its reason exactly matches the previous shipped text, preserving user-edited versions and existing votes.

## Navigation themes

- Synergies and Counterpicker navigation tabs now use matching green styling.
- Removed the visible numeric badges from Synergies and Groups tabs while retaining their underlying elements for existing app event handlers.
- Playbook now uses a dark-blue checker pattern inspired by the blank tactical canvas.

## Tactical board resizing

- Removed the 60% board-size ceiling from both the legacy and active resize handlers.
- Shape, pen, arrow and wall dimensions can now expand to the full board area.
- Reduced the resize minimum to 0.35% to allow finer shrinking.
- Existing placement clamping still keeps resized objects within the board.

## Preserved functionality

- Built from V13.4. Supabase schema, project configuration, Vercel configuration, map assets, saved-play format, collaboration logic, vote totals and user-created groups/rules remain unchanged.
- No live Supabase database or Vercel deployment was modified.

## Validation

- JavaScript syntax checks: completed in build validation.
- CSS parsing: completed in build validation.
- JSON validation: completed in build validation.
- ZIP integrity: completed in build validation.
- No live browser interaction test or live Supabase session was performed as part of this build.
