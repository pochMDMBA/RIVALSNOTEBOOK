# RIVALSNOTEBOOK V13.18 Release Notes

## Playbook pen arrows

- Live drawing previews now show only the stroke. The arrowhead is not created or displayed while the pointer is moving.
- On pointer release, the finished pen object is rendered with its arrowhead.
- The shaft is shortened to the arrowhead base, and the connector terminates at the center of that base so the shaft joins the triangle at its base rather than running to or through the tip.
- The same release-time rendering applies to solid-arrow and dashed-arrow freehand tools.

## Text fill and border controls

- Replaced the visible NONE checkboxes with compact themed color popovers.
- FILL opens a color picker plus an icon showing a white fill tile crossed by a red diagonal for no-fill.
- BORDER opens a color picker plus a borderless-square icon crossed by a red diagonal for no-border.
- Removed the external checkmark/NONE labels. The no-fill and no-border states continue to use the existing saved style flags, preserving compatibility with saved text boxes and defaults.
- TEXT remains a simple color picker popover.

## Compatibility and validation

- Based on V13.17. Existing Supabase schema, credentials/configuration, map assets, and saved-play data structures are preserved.
- No live Supabase database or Vercel deployment was modified.
- Static JavaScript, CSS, JSON, HTML-ID, asset-path, and ZIP integrity checks were run. A live hosted-browser interaction test has not been completed.
