# RIVALSNOTEBOOK v13.36 Release Notes

Built from the v13.35 deployment package.

## Synergies layout
- Reverted the Synergies panel's layout and scroll-container handling to the original v13.32 implementation.
- Removed the v13.34 sticky-heading DOM move and its grid-row/scroll styling.
- Removed the v13.35 second layout re-parenting observer and flex-layout override.
- Preserved the base v13.32 structure: the team heading and lineup remain in their original positions, and Recommended Synergies, recommendations and official Team-Ups stay inside the original result-scroll region.
- Retained all Synergies content, team selection, votes, edit controls and add actions. Only the later layout overrides were reverted.

## Pen arrowhead scaling
- Pen arrowhead length now scales directly with the pen stroke width, up to seven times the stroke width.
- Arrowhead half-width is now 30% of its length, so both the length and width grow or shrink with the stroke.
- The arrowhead is also limited to 35% of the drawn path length, preventing it from consuming a short stroke.
- Applied the same geometry in final rendering and pointer-release bounds calculation so saved arrows, selection bounds and redraws remain consistent.

## Preserved
- v13.35 thickness slider synchronization and Saved Play discard confirmation.
- v13.34 Pocket Strat Play workflow, text-box fill opacity, number-marker resizing and shape settings.
- Repository cleanup, all 63 canonical map assets, Supabase configuration/schema and Vercel configuration.

## Validation
- Both pen-arrow geometry call sites use the same proportional formula.
- v13.34 and v13.35 Synergies layout installers were removed without removing their unrelated Playbook features.
- JavaScript syntax and package checks passed.
- Live browser verification of Synergies layout and pen arrow appearance is still recommended after deployment.
