# RIVALSNOTEBOOK v13.27 Release Notes

## Deployment-safe map cover images
- Embedded all 17 map cover assets from `assets/maps/covers/` directly into `index.html` as data URLs.
- The map cover loader checks the embedded cover registry before trying static file paths.
- Map-library cards and the selected-map thumbnail no longer depend on relative cover paths, avoiding the GitHub/Vercel nested-path issue.

## Competitive Domination 2D layouts
- Registered 18 top-down 2D floor-plan image URLs for Royal Palace, Birnin T’Challa, Hell’s Heaven, Krakoa, Celestial Husk and God Quarry.
- Each area is represented by a number button (`1`, `2`, or `3`) with a separate **2D** button directly below it.
- The selected area name remains visible beneath the controls in uppercase, without the word “Submap”.
- The map list label reads “3 AREAS · COMPETITIVE”.
- Corrected God Quarry's area order to match the published layout sequence: Halls of All-Knowing, House of Ideas, Confessional Eternity.
- The 2D images are referenced as direct HTTPS URLs hosted by `rivals.gs`. They are not copied into this ZIP and require the browser to reach that source. The numbered screenshot slots remain ready for later local uploads.

## Textbox editing
- Added a document-level capture handler for double-clicking an existing textbox or number marker.
- The editor opens before older board handlers can intercept the gesture, including when Select/Move is the active tool.
- Existing single-click Text-tool editing and editor-specific Ctrl+A behavior are preserved.

## Validation
- All 17 cover assets are present and embedded in the HTML registry.
- All 18 Domination layout URLs are registered and map to the correct area names.
- `map-library.json` parses and mirrors the runtime Domination layout metadata.
- All inline JavaScript blocks and external JavaScript files are syntax-checked.
- CSS blocks are parsed, duplicate HTML IDs are checked, and ZIP integrity is verified.
- No Supabase schema or configuration was changed. No GitHub push or Vercel deployment was performed.

## Image source attribution
- `https://marvelrivals.gg/maps/` was used to verify the competitive map catalogue and map names.
- The top-down layout images are referenced from individual layout pages on `https://rivals.gs/`; direct image URLs are recorded in `map-library.json`.
