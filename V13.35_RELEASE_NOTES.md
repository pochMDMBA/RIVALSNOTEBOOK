# RIVALSNOTEBOOK v13.35 Release Notes

Built from the v13.34 deployment package.

## Synergies layout restoration
- Restored the results panel to a simple vertical layout, matching the last working Counter Picker-style structure.
- Kept the Recommended Synergies heading and Add Synergy action on one fixed row above the scrollable results.
- Kept the Global Community Ranking ribbon inside the scrolling results region so it cannot create an extra grid row or overlap the results panel.
- Restored full-width content and a flexible footer. The lineup, section title and footer remain outside the scrolling results area.

## Thickness slider
- Fixed the percentage slider being reset to raw pen/shape units by the legacy tool-settings renderer after every redraw.
- Resynchronizes the displayed percentage from the selected object after board redraws, selection changes and slider input.
- Pen and shape modes keep their own independent physical scales. Pen strokes use the calibrated 0.05%–0.35% board-width range; shape borders retain the 0.05–12 px range.
- The slider remains adjustable across the full 1–100% track for existing and newly drawn objects.

## Saved Play discard confirmation
- Reloading the currently active Saved Play prompts **Discard Changes?** when the current map/view board differs from the snapshot loaded in this browser tab.
- Choosing **DISCARD CHANGES** restores the saved board snapshot before the existing map/view transition hooks execute, then reloads the Saved Play.
- Choosing **CANCEL** leaves the current board and selection untouched.
- A new baseline is recorded after a Saved Play is loaded or explicitly saved, so unchanged boards do not prompt.

## Repository cleanup
- Retained canonical map and cover assets under `assets/maps/` and `assets/maps/covers/`.
- Removed unused root-level map uploads and redundant numbered duplicates only after verifying they were not referenced by the map library, service worker, HTML, JavaScript or stylesheet sources.
- Preserved favicon/app icons, Supabase configuration and schema, map metadata, and the canonical assets required by current maps.

## Preserved
- v13.34 pen/shape thickness calibration, marker resizing, textbox opacity, Pocket Strat Play action and map/view isolation.
- Existing Supabase configuration/schema and Vercel configuration. No database migration is required.

## Validation

- ZIP integrity and JSON parsing checked.
