# RIVALSNOTEBOOK v13.52 Release Notes

## Live Counterpicker and Synergies refresh
- Fixed a repeated MutationObserver feedback loop. The UI installer previously rewrote unchanged HIDE/SHOW button text on every observed page mutation, continuously triggering itself and eventually making the page unresponsive or stale.
- Counter and Synergy controls now update their button labels and expanded states only when values actually change.
- Added a lightweight refresh when the browser tab becomes visible or regains focus. When Supabase is connected, community vote totals are refreshed before the application redraws.

## Restored points calculations
- Reverted the v13.51 per-matchup maximum aggregation. Counter Pick totals again use the original total of all applicable matchup scores, and Synergy suggestion totals again sum all contributing synergy entries.
- Removed the rendered-DOM counter score parser that was incorrectly reading an empty result and replacing valid Counterpicker totals with zero.
- Preserved the original base scoring: Counter Picks use their tier score plus vote points; Synergies use Strong 100, Moderate 70 or Situational 40, with the existing Official Team-Up and vote additions.

## Removed community labels
- Removed the “GLOBAL COMMUNITY RANKING / Shared upvotes update for everyone” ribbon.
- Removed the “COMMUNITY UPVOTES / Ranked with votes from every signed-in RivalsNotebook account” ribbon.
- Removed the long Counter strength / Reddit guidance footer paragraph from the Counterpicker.

## Cache and release
- Updated the application title and package version to v13.52.
- Bumped runtime script cache keys and the UI patch guard to v13.52.

No Supabase migration is required. Existing workspace data, votes, comments, maps and Playbook records retain their existing formats.
