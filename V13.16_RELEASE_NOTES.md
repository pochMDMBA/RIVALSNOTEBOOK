# RIVALSNOTEBOOK V13.16 Release Notes

V13.16 is based on V13.15. It updates the Playbook toolbar and text-object editing while preserving the existing application, map assets, Supabase schema/configuration, and Vercel settings.

## Playbook updates

- Reduced the default dimensions of normal hero/enemy tokens and icon-only hero/enemy tokens.
- Condensed the SAVE AS button within its action cell.
- Replaced ambiguous TYPE glyphs with distinct SVG previews for solid stroke, dashed stroke, arrow stroke, and dashed arrow stroke.
- Added green as a fifth preset pen color. The custom color picker remains available.
- Added independent `NO FILL` and `NO BORDER` options for text boxes. Explicit state classes ensure older high-priority theme rules cannot restore a border or background after those options are selected.
- Added a numeric font-size input (6–48 px) with minus/plus buttons. The number can be edited manually. The font-size stepper sits directly below FILL / BORDER / TEXT controls.
- Added saved height to text objects and enabled the normal bottom-right resize handle plus the editing surface resize grip to change width and height independently. Text boxes can be resized toward a square shape.
- Text fill, border visibility, text color, font size, width, and height are retained on the saved text object and restored when editing or reloading a play.

## Synergies

- Removed the gray background and border from the sticky `Recommended Synergies` heading so it follows the same unfilled heading treatment as `Recommended Counter Picks`.

## Validation

- All inline JavaScript blocks passed Node syntax checks.
- `rivalsnotebook.js` passed Node syntax validation.
- All embedded CSS blocks parsed with `tinycss2` without parse errors.
- JSON files parsed successfully.
- Static HTML IDs were checked for duplicates.
- ZIP integrity and referenced local assets were checked.

No Supabase database schema, credentials, live data, or production deployment was changed. Live browser interaction testing against the deployed Vercel site has not been performed; use a Vercel Preview before promoting this package to production.
