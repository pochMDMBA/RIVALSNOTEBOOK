# RIVALSNOTEBOOK V13.19 Release Notes

## Playbook arrow geometry

- Solid-arrow and dashed-arrow pen strokes still display only their shaft while the pointer is moving. No arrowhead is shown in the live preview.
- On pointer release, the renderer calculates one triangle-base centre from the release-tip direction. The SVG shaft ends at that exact base-centre point; it is never drawn to the triangle tip.
- The triangle base corners are derived from the same centre point. Dashed arrows also add a short, solid terminal lead to the same point so a dash gap cannot visually disconnect the shaft from the base.
- The arrowhead is rendered as an SVG polygon after release, using the final saved pen geometry. Short strokes cap the head length so it cannot consume the entire shaft.

## Direct text controls

- FILL, BORDER and TEXT now expose direct native color-picker buttons. The previous popup/dropdown layer and its interaction handlers have been removed.
- Separate NO FILL and NO BORDER toggle buttons appear below their respective color pickers.
- A separate **B** button appears below TEXT. It toggles bold on selected and newly created text boxes, and the setting is saved with the text object and default style.
- Choosing a fill or border color restores that property if its corresponding no-fill/no-border state was active.

## Font-size control

- Removed the PX label.
- Increased the numeric-field allocation and button sizing. The value remains centered and fully visible between the minus and plus controls.

## Compatibility and validation scope

- Based on V13.18. Supabase schema, Vercel configuration, JPEG map assets, existing saved-play records and prior text-style data remain compatible. Existing text boxes default to non-bold unless already saved with a bold state.
- This package contains static validation only unless separately stated: syntax, JSON, asset-reference, package metadata, and ZIP-integrity checks are recorded after the build. No live browser or hosted Vercel/Supabase test is implied by those checks.
