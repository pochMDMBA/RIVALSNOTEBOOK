# RIVALSNOTEBOOK V13.19 Release Notes

**Baseline:** V13.18  
**Release:** V13.19

## Changes

### Arrowhead geometry
- Replaced the separate arrowhead/shaft endpoint calculations with a shared arrow-geometry helper.
- The solid or dashed shaft now ends at the calculated midpoint of the triangle's base. The triangle's base corners are derived from that same midpoint, so the shaft endpoint and base midpoint use the same coordinates.
- The final short connector segment is drawn to the base midpoint to close the last dash gap where needed.
- The arrowhead remains absent during pointer movement and is generated only when the drawing is committed on release.

### Text style controls
- Removed the Fill, Border, and Text dropdown/popover UI.
- Each color control is now a direct color input.
- Added a separate **NO FILL** button under FILL.
- Added a separate **NO BORDER** button under BORDER.
- Added a separate **B** bold toggle under TEXT.
- Bold state is stored on text objects and restored when board items are loaded.

### Font size control
- Removed the PX label.
- Widened the numeric input, centered the value, and retained the minus/plus controls with a more balanced layout.

## Validation performed
- All 27 inline JavaScript blocks passed `node --check`.
- External JavaScript files passed `node --check`.

- 44 CSS sources/blocks parsed with no CSS syntax errors (1,504 rules).

## Deployment note
This package has not been deployed to the user's Vercel project. A live browser interaction test against the hosted application was not completed. Test solid and dashed arrows, NO FILL, NO BORDER, bold text, and saved/reloaded text boxes in a Vercel Preview deployment before promoting to production.

No production Supabase data or schema was modified. V13.18 remains the untouched fallback package.
