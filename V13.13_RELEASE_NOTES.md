# RIVALSNOTEBOOK V13.13

## Focused fixes

### Enemy placement control
- Enemy is placed immediately beside Strategist in the same compact row as All / Vanguard / Duelist / Strategist.
- The button remains a separate placement mode and retains its red active state.

### Text placement
- Text button now explicitly arms a one-click placement action in capture phase, preventing legacy toolbar listeners from toggling it back to Select.
- The next left-click on the board creates and focuses an editable text rectangle at that position.
- Includes a direct textarea fallback if the shared editor entry point is unavailable.
- Leaving the editor or completing/cancelling it returns to Select.

### Map defaults
- Choosing a new map selects Point A when available, even when a 2D overview exists.
- Stale local 2D defaults migrate to Point A for a fresh workspace.
- Existing saved plays retain their explicitly saved current map/view.

### Independent map-view boards
- A, B, C and 2D use separate board data keys per map.
- Switching views captures the outgoing board and restores only the target view's items.
- First-time views start empty; they never inherit the elements from the previously open view.
- Saved plays created in earlier builds receive a one-time migration: the saved current map/view is canonical, and only byte-for-byte duplicate copies in other views are cleared. Distinct board sets are retained.
- Unsaved prior-version drafts migrate per map/view; byte-for-byte duplicate copies of the last active board are cleared from other views, while distinct view content is retained. If Point A becomes the new default after a session last used 2D, the old content remains under 2D and Point A starts empty.

## Validation
- JavaScript syntax validation of all inline scripts and external JS.
- CSS parsing and HTML structure checks.
- JSON validation and ZIP integrity checks.
- No live Supabase database or Vercel production deployment was modified.

Live browser interaction and hosted deployment testing remain outstanding; deploy to Vercel Preview before production.
