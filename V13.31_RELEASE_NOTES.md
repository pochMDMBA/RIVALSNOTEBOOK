# RIVALSNOTEBOOK v13.31 Release Notes

Built from the v13.30 deployment package.

## Playbook controls

- The entire **Select a saved play** button now responds to pointer interaction, not only the far-right area. Pointerdown handling and explicit stacking/hit-area styling keep the full button clickable.
- The saved-play label shows the play name and map name only. Submap view-set strings such as `1 + 2D, 2 + 2D` are no longer displayed. The visible button rectangle is hit-tested at capture phase so clicks across its full width open the menu reliably.
- Map-selection cards show only the map name. Redundant `2D + Points A-C` and other view captions have been removed.
- The currently selected Domination submap name is centered beneath the numbered and 2D selectors, including long names such as Imperial Institute of Science.

## Text editing

- Replaced the cloned `contenteditable` board `div` with a native textarea editor for text boxes and number markers.
- Select/Move supports double-click editing. Text mode supports single-click editing of an existing text box or number marker.
- The second pointer press is detected by the stable board-item ID before selection redraw can replace the DOM node; this makes double-click editing reliable in Select/Move. The Text tool opens existing text with a single click.
- The active textarea no longer carries the draggable `.board-item` class, so board drag and marquee handlers cannot consume keystrokes or text-selection pointer events.
- Text input autosaves, commits on blur, and is persisted when switching tools.
- Ctrl+A uses the textarea's native selection so only the editor contents are selected.

## Tool defaults

Added a full-width horizontal **DEFAULTS** button at the top of the Tools panel. It resets defaults for newly created objects without changing existing board objects:

- Shapes: yellow, 100% fill opacity, 100% border opacity, 2.4px border thickness (one-fifth of the 12px maximum), and 100% overall opacity.
- Text: text color `#FFC800` (RGB 255, 200, 0), fill `#505050` (RGB 80, 80, 80), no border, normal weight, and 12px font size.
- Freehand drawing: yellow, 100% opacity, 2.4px stroke thickness, and solid stroke type.

## Shape placement

- Clicking a shape, wall, arrow, or number marker searches the board for a genuinely vacant position before placement.
- The placement search checks existing board-item bounds, includes a small clearance gap, and prefers a free position near the board center. If no unoccupied position exists, it does not overlap another object and instead prompts the user to move or remove an object. Drag-and-drop placement remains tied to the pointer.

## Preserved functionality

- Existing Convoy, Convergence, and Domination map assets and their cover/2D separation.
- Six Domination cover images and all 18 Domination 2D layout references.
- Map-specific saved-play isolation introduced in v13.30.
- Existing Supabase configuration, schema, Vercel configuration, and application data structure.
