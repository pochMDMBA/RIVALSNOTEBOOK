# RIVALSNOTEBOOK v13.50 Release Notes

## Baseline restoration
- Rebuilt from the exact v13.47 source tree, preserving its application features, maps, Playbook tools, community voting and collaboration code.
- Replaced the v13.48/v13.49 source chain instead of carrying those changes forward as incremental patches.
- Updated the actual `index.html` entry point, application title, package version and README to v13.50.

## Synergies content controls
- Moved Recommended Synergies, Show Only Upvoted Synergies, Include Group Rules and Add Synergy into the scrolling results window, above Global Community Ranking.
- The controls are normal content, not a sticky/fixed header, and remain available when recommendations refresh.
- Include Group Rules is checked by default. Unchecking it hides suggestions generated from Group Synergy Rules while preserving regular hero-to-hero synergies.
- The Upvoted filter retains its account requirement and vote-direction behavior.

## Synergy Strength
- Added a shared Synergy Strength selector to both Add Synergy and Add Group Synergy.
- Strong: 100 base points; Moderate: 70; Situational: 40.
- Official Team-Ups add 25 points. Each upvote adds 5 points.
- Group-generated recommendations inherit the strength of their parent Group Synergy Rule.
- Strength is retained while editing and shown on synergy cards and Group Synergy Rule entries.
- Older entries without a stored strength default to Strong.

## Startup and cache reliability
- Removed a legacy v13.36 `document.title` assignment from the Playbook upgrade script. The application entry page remains the single source of truth for the displayed release version.
- Corrected the UI patch duplicate-load guard.
- Updated runtime script query versions to v13.50 to avoid stale locally cached scripts.
- Added no-cache metadata and Vercel headers for the HTML entry page.
- Kept external script dependencies in the existing ordered loader chain.

No Supabase migration is required. Existing workspace data, votes, comments, maps and Playbook records retain their existing formats.
