# RIVALSNOTEBOOK v13.34 Release Notes

Built from the v13.33 deployment package.

## Pen thickness accuracy
- Recalibrated the shared thickness slider against the pen renderer, which interprets `penWidth` as a percentage of board width.
- Pen thickness now ranges from 0.05% to 0.35% of board width. The pen default is 25% of that range, about 1.2 CSS pixels on a 1,000-pixel-wide board and about 1.96 pixels on a 1,600-pixel-wide board.
- The pen readout shows the slider percentage and estimated current pixel width. Shape borders retain their separate pixel scale and 40% default (4.8 px on the 12 px scale).
- A one-time migration corrects the previous v13.33 4.8% pen default and the early v13.34 preview default, including default-width saved pen strokes, while preserving other custom widths.

## Synergies heading
- Moved **Recommended Synergies** above the independently scrolling recommendation list.
- The heading remains visible while synergy and official team-up results scroll, following the Counter Picker layout.

## Pocket Strat viewing
- Removed **ADD POCKET STRAT** buttons from Synergies and Counter Picker.
- Kept the linked **PLAY** action for saved Pocket Strats.
- **PLAY** now opens the selected Pocket Strat directly in the Playbook rather than opening a popup.
- Before switching, the current Playbook is persisted. Unsaved boards containing objects are saved as a new `(DRAFT)` play; an already-saved active play is saved under its existing name.
- The Pocket Strat's saved map, view and board objects are restored in the Playbook. No connector arrow or separate popup is created.

## Number marker resizing
- Added a dedicated corner drag handle beside a selected number marker, outside the marker's own hit area.
- Dragging the handle changes the marker scale. Circle diameter, border width and number font size grow or shrink proportionally.
- The dedicated sibling handle avoids the older board drag and text-edit gesture handlers.

## Preserved
- Existing shape fill opacity, textbox fill opacity, shape palette, saved-play map/view isolation and all map assets.
- Supabase configuration/schema and Vercel configuration. No database migration is required.

## Validation
- JavaScript syntax, CSS parsing, JSON parsing and deployment ZIP integrity checks passed locally.
- All 63 bundled map images were present and registered.
- Full live browser pointer testing is still recommended after deploying the new package.
