# RIVALSNOTEBOOK v13.44 Release Notes

Built from the current `main` branch and includes the previous v13.43 Counterpicker and Synergies behavior.

## Counterpicker and Synergies

- Moved matchup `VS + hero icon + hero name` to the right side of Counterpicker matchup rows.
- Moved each Synergies teammate identity to the right as `WITH + hero icon + hero name`.
- Moved Synergies EDIT actions directly below their descriptions.
- Removed decorative Group Synergy icons from the normal Synergies tab while retaining the icon in the separate Group Synergy Rules tab.
- Added HIDE / SHOW to each suggested-hero Synergies card beside the aggregate points. It collapses teammate details while preserving the suggested hero and total points.
- Retained Counterpicker HIDE / SHOW controls beside the summary points and counter tier.

## Playbook

- Increased the stroke-thickness slider and stored-drawing limits from 12 to 24.
- Scaled standard arrowheads with the selected stroke width.
- Adjusted freehand arrowhead geometry so it continues to grow with thicker strokes without extending beyond the arrow line.

## Cleanup

- Removed the obsolete root `supabase-schema.sql` and `supabase-permissions-fix.sql`, both of which contained OLFACULATOR fragrance-library SQL. The active RIVALSNOTEBOOK schema, migration, and verification script remain in `supabase/`.
- No credentials or Supabase database migrations were changed.
