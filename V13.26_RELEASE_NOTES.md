# RIVALSNOTEBOOK v13.26

## Competitive Domination map library

- Added six competitive Domination maps: Royal Palace, Birnin T’Challa, Hell’s Heaven, Krakoa, Celestial Husk and God Quarry.
- Each map opens on Submap 1 and exposes Submap 1, Submap 2 and Submap 3 as independent Playbook views. Existing Convoy and Convergence Point A/B/C and 2D behavior is retained.
- Added the official section names beside the selector and on the no-screenshot placeholder state.
- Added local SVG cover placeholders for the six map cards. Actual submap screenshot paths are intentionally blank until supplied, preventing broken image requests.
- Submap board content is keyed independently by map and submap, preserving separate saved tactical objects for each area.

## Text tool editing

- With the Text tool active, a single click on an existing text box or number marker opens its inline editor instead of moving the board object.
- Double-click editing remains available when the Select/Move tool is active.
- Ctrl+A / Cmd+A inside the inline editor explicitly selects the editor’s text only. It no longer triggers board-wide selection.
- Ctrl+A / Cmd+A outside a text editor continues to select all board objects. Native select-all behavior remains available in ordinary form inputs.

## Preserved

- v13.25 Museum of Contemplation embedded-cover fallback, mouse marquee selection, middle-button panning and textbox persistence fix.
- Existing Convoy/Convergence map assets, Supabase configuration and schema, Vercel configuration, and deployment files.
- No Supabase schema migration is required. No live GitHub or Vercel deployment is performed.
