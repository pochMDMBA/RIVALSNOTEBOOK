# RIVALSNOTEBOOK v13.6 release notes

## Playbook canvas and movement

- Removed the internal 0–100% coordinate clamp from the saved-item normalizers. Board objects can now be moved partially beyond the visible canvas edge; a narrow visible portion and repositioned resize/rotate handles remain accessible for recovery.
- Expanded saved board-object width and height bounds so shapes, circles, arrows, walls, pen marks and inserted images are not stopped at an internal 100% size ceiling.
- Preserved off-canvas object coordinates in the initial local-storage hydration path as well as in the active Playbook normalizer, so positions do not snap back after reload.
- Raised the zoom ceiling from 200% to 500%. The numeric zoom control accepts values up to 500%.

## Drawing and shape controls

- Expanded opacity slider hit area and track width. The numeric opacity value can be clicked or keyboard-activated to restore 100% opacity directly.
- Shape fill opacity and outline opacity now have independent controls and persisted values. The controls update selected shapes while dragging and set defaults for newly created shapes.
- Lowered the minimum pen and shape stroke thickness to 0.05 and retained that value in saved-board normalization.
- Thickness changes apply to selected shapes, pens, arrows and walls while the slider is being dragged, with the updated drawing rendered and persisted during adjustment.
- Pen strokes capture color, opacity and thickness at pointer-down. The saved stroke uses those captured settings so the final result matches the live preview.

## Navigation and group rules

- Counterpicker navigation is red. Synergies retains its green navigation treatment.
- Group Counter Rules show the source and target group as two sides divided by a visible vertical border rather than an arrow.
- Group Counter and Group Synergy editors include a switch action to convert a rule to the other rule type. During conversion, the new rule is saved before the original rule is removed.
- Hero selectors in these group-rule editors use compact hero portraits with search and selected-hero previews.
- Corrected the Hero Groups delete control to display one plain X glyph without overlapping pseudo-element icons.
- Removed the “0 Suggestions” badge from the Allied Team panel in Synergies while retaining the underlying counter element for the rendering logic.

## Backend and deployment

- Based on V13.5. No Supabase schema migration is required for these front-end-only changes.
- Supabase schema, connection configuration, Vercel configuration, tactical map library and map assets are preserved.
- No production database or deployment was modified as part of this package build.

## Validation and limitations

- Inline JavaScript syntax, CSS parsing, JSON files, static asset references and ZIP integrity were checked.
- Automated live browser interaction testing was blocked by the execution environment, so verify edge dragging, zoom, opacity, thickness, pen color, group-rule conversion and the Hero Groups delete control in a Vercel Preview before promoting the package to production.
