# RIVALSNOTEBOOK v13.55 Release Notes

## Global Synergy ranking
- Removed the separate Vanguard / Duelist / Strategist result columns from the Synergy recommendation list.
- All suggested heroes now appear in one global ranking, ordered by the sum of their matching synergy points across the selected allied team.
- Condensed suggestion cards are appended in the already-sorted aggregate order, so a 200-point suggestion appears above 100-point suggestions regardless of hero role.
- The per-pair points, official Team-Up 100-point base score, and +5 points per upvote are unchanged.

## Submitter attribution
- Removed the generic source/byline text (including "Group synergy · ...") from the top of each Synergy description.
- User-created synergies and Group Synergy Rules now display **Submitted by [Username]** when an account identity is available, using the account's username/display name or email name as fallback.
- Unauthenticated/local entries display **Submitted by Developer**.
- Removed the redundant Group Rule tag from the bottom of generated entries. Group status remains available beside EDIT.
- Preserved external source links separately as Source links for non-generated Synergy entries.

## Hero role categories
- Replaced the visible **Support** category label with **Strategist** across the hero roster, role filters, Counterpicker role headings, and Group role views.
- The hero role data and existing Strategist styling remain unchanged.

## Cache and release
- Updated the app title and package version to v13.55.
- Bumped the runtime script cache keys and UI helper guard to v13.55.

No Supabase migration is required. Existing groups, rules, synergies, counters, votes, comments, maps and Playbook records retain their existing formats.
