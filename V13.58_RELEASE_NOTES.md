# RIVALSNOTEBOOK v13.58 Release Notes

## Synergy recommendation columns
- Restored the three Recommended Synergies columns: Vanguard, Duelist and Strategist.
- Suggested heroes are assigned by the suggested hero's role, using the shared role resolver. Both legacy Support and current Strategist role values map to Strategist.
- Combined synergy points are summed across the selected teammates, then sorted highest-first only within the matching role column. A high-scoring hero cannot jump ahead of a hero in another role.
- Each role column remains visible even when it has no current suggestions.

## Preserved behavior
- Retained official Team-Ups, community/group synergies, contribution points, upvotes, comments, edit controls and submitter attribution.
- Retained the Synergies roster role dividers and removal of secondary Tank/Damage/Strategist/Flexible labels. Counterpicker labels remain unchanged.
- No database migration or saved-data format change is required.

## Release
- Updated app title and package version to v13.58.
- Bumped runtime cache keys to v13.58.
