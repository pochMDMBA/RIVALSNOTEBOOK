# RIVALSNOTEBOOK V13.11 Release Notes

## Vercel-safe Point A/B/C images
- Embedded all 18 optimized Point A/B/C JPEGs directly into `index.html` as a self-contained fallback.
- Retained the corresponding JPEG files under `assets/maps/` for normal static hosting and local use.
- The map loader now prefers the embedded JPEG data and falls back to static asset URLs if needed.
- Reduced the supplied point JPEGs to 1600 × 1000, progressive JPEG, quality 82 to keep the self-contained HTML practical while retaining map detail.
- Updated the image cache token to `rnmap=1311`.

## Playbook tool spacing
- Added clearer vertical separation between Type and Color controls.
- Standardized button gaps, dimensions and centered color swatches to match the Tactical Shapes palette.

## Text tool redesign
- Clicking the board with the Text tool now creates a text rectangle and immediately focuses it for typing.
- Removed the visible check and X actions. Text saves automatically on blur; Ctrl+Enter also finishes editing; Escape cancels.
- Double-clicking an existing text box opens the same inline editor.
- Added independent Fill Color, Border Color and Text Color pickers.
- Selected text boxes update live when their colors are changed.
- Added backward-compatible defaults for existing saved text items.

## Preserved
- V13.10 application data, maps, heroes, rules, Supabase configuration/schema and Vercel configuration.
- No live Supabase data or production deployment was modified.

## Validation
- 18 point JPEGs embedded and retained as files; all decoded successfully.
- Inline JavaScript syntax and CSS/JSON validation performed during packaging.
- ZIP integrity checked.
- Live Vercel deployment testing remains necessary to confirm the user's project configuration and production browser behavior.
