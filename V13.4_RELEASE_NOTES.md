# RIVALSNOTEBOOK V13.4 Release Notes

## Synergy portrait display

- Corrected hero artwork sizing in the three role-based Synergy recommendation columns.
- Replaced the shallow, clipped portrait frame with a centered square frame so each source hero image is displayed in full using `object-fit: contain`.
- Removed portrait-frame clipping for these Synergy tiles while retaining the existing role-column layout, recommendation ordering, labels, and card content.
- Reduced the portrait frame slightly on narrow mobile screens to prevent horizontal overflow.

## Playbook icon-only transform controls

- Restored the rotate and resize handles for a single selected hero while **HERO ICONS ONLY** mode is active.
- Icon-only hero items can now be resized and rotated using the same board controls as labelled hero items.
- The icon-only appearance remains unchanged when the item is not selected. Existing multi-selection behavior is unchanged.

## Preserved functionality

- Built from V13.3. No recommendation scores, roster data, hero image URLs, team selection logic, board item data, Supabase schema/configuration, Vercel configuration, maps, or collaboration behavior were changed.
- No live Supabase data or deployed Vercel project was modified.
