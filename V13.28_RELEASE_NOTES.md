# RIVALSNOTEBOOK v13.28 Release Notes

## Domination cover images
- Replaced all six temporary SVG placeholders with the actual map-card thumbnails cropped from the user-supplied screenshot of `https://marvelrivals.gg/maps/`.
- Bundled the six JPEG covers under `assets/maps/covers/` and embedded their exact JPEG bytes in `RN_MAP_COVER_IMAGES` for reliable GitHub/Vercel delivery.

## Restored tactical 2D maps
- Fixed the asset resolver so cover images and tactical map layers use separate registries.
- Cover images are resolved only from `RN_MAP_COVER_IMAGES`; map layers and point screenshots are resolved only from `RN_POINT_MAP_IMAGES` or their original static/remote paths.
- This prevents same-basename collision (for example, `assets/maps/yggdrasil-path.jpg` being replaced with `assets/maps/covers/yggdrasil-path.jpg`).
- Preserved all existing Convergence/Convoy map paths and all 18 Domination 2D floor-plan URLs from `rivals.gs`. The submap 2D layouts are still independent URLs and are not mapped to cover thumbnails.
- Increased the tactical asset cache token to `rnmap=1328`.

## Domination area names
- Updated the numbering to match the published map guides where the three area order is documented: Royal Palace, Birnin T’Challa, Hell’s Heaven, Krakoa and God Quarry.
- Carried forward the previous Celestial Husk area names and order because the available guide does not document its numbered submap sequence.
- Kept the three controls numbered `1`, `2`, `3`, each with its own 2D option beneath it.

## Playbook text editing
- Double-clicking a textbox or number marker now opens the persistent inline editor in both Select/Move and Text tools.
- Added a second-click pointer handler so the editor opens before legacy board handlers can consume the double-click.
- Retained the existing content-only Ctrl+A behavior while the textbox editor is active.

## Map label styling
- Restyled the selected submap name as a compact, subdued dark-blue panel with notebook typography and a muted border, matching the Playbook controls.

## Preserved
- All existing hero, counterpick, synergy, group and Playbook data structures.
- Existing tactical point JPEGs and the Museum of Contemplation embedded-cover fix.
- Original Supabase configuration, SQL files and Vercel deployment settings.
- Existing Convoy and Convergence map definitions and their image URLs.

## Validation
- Confirmed the six Domination cards point to local JPEG files and the embedded cover registry bytes match those files.
- Confirmed no Domination SVG placeholders remain referenced.
- Confirmed tactical 2D assets continue to resolve through the map/tactical path rather than the cover registry, including the Yggdrasill Path basename collision.
- Confirmed all 18 Domination 2D layout URLs are preserved and unique.
