# RIVALSNOTEBOOK v13.64 Release Notes

## Counterpicker readability
- Increased Counterpicker matchup description text from 9px to 12px with improved line spacing.
- Kept hero names, action controls, score badges and other compact labels at their existing sizes.

## Counterpicker Group Rules filter
- Restored an **Include Group Rules** checkbox beside the Counterpicker filters.
- Checked by default. Unchecking it hides generated Group Counter Rule matchups; checking it restores them.
- Existing regular Counter Picks, vote filtering, points and matchup ordering are unchanged.

## Counterpicker attribution cleanup
- Removed generic "Community tip", "Group Rule" and source/byline labels from matchup rows.
- Retained only **Submitted by [Username]** for user-authored entries.
- Improved Group Counter Rule author lookup so generated matchups use the parent rule's author name.

## Release
- Updated the application package to v13.64.
- Bumped dynamically loaded script cache keys to v1364.
- No Supabase migration required.
