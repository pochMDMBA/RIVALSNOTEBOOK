# RIVALSNOTEBOOK v13.53 Release Notes

## Unified Synergy recommendations
- Official in-game Team-Ups now appear in the same Recommended Synergies list as community and group-derived synergies.
- All entries are ranked together by points within their suggested-teammate role columns.
- Official Team-Ups retain a clear **OFFICIAL TEAM-UP** label and use a 100-point base score. Each upvote continues to add 5 points.
- Removed the separate Official Team-Ups section and its separate Add Team-Up control. Official entries can still be created or edited from Add Synergy using the Official in-game Team-Up ability checkbox.
- Updated the Add Synergy guidance and scoring descriptions to reflect the official 100-point base.

## Counterpicker
- Counterpicker now displays every recommendation in each role column by default.
- Removed the bottom Show All Counterpicks expansion control.

## Bulk detail controls
- Added **HIDE ALL / SHOW ALL** to Counterpicker to collapse or restore all counter recommendation details and open comment panels.
- Added **HIDE ALL / SHOW ALL** to Synergies to collapse or restore all synergy descriptions and open comment panels.

## Cache and release
- Updated the application title, package version and deployment notes to v13.53.
- Bumped runtime script cache keys to v13.53 so the updated UI loads without stale cached scripts.

No Supabase migration is required. Existing workspace data, official flags, votes, comments, maps and Playbook records retain their existing formats.
