# RIVALSNOTEBOOK v13.60 Release Notes

## Counterpicker roster
- Added horizontal separators between visible role groups in the left Counterpicker roster, matching the Synergies roster.
- Removed secondary Tank, Damage, Strategist and Flexible descriptors beside the primary colored role pills.

## Account Display Name
- Added a Display Name field during account creation.
- Added a signed-in profile field and Save Name action when clicking the account button.
- Display Name is stored in Supabase Auth user metadata, used for account buttons and preferred for submission attribution.
- Existing accounts without a Display Name continue using the email-name fallback until they set one.

## Groups
- Removed the Community indicator from Group Synergy cards while retaining the Official indicator for official entries.
- Centered the Group Synergy name combination.
- Group Counter Rules now show numeric points instead of strength labels and multipliers.
- Group Synergy cards now show numeric points.

## Release
- Updated application and package version to v13.60.
- Bumped app, script and stylesheet cache keys.
- No database schema migration is required; Display Name is saved in Supabase Auth metadata.
