# RIVALSNOTEBOOK V13.9 Release Notes

## Map point images
- Added resilient map image loading that tries the app URL, each parent path, root assets and the project-folder deployment path.
- Added cache-busting for map images to avoid stale failed requests after redeployment.
- Map cards, current-map covers and the active tactical-board background now share the same loader.
- Point A, Point B and Point C controls use a 2-by-2 layout with wrapping labels that stay inside their borders.
- Map point assets remain JPEG files. No WebP point images are used.

## Synergy and counter rule editor
- Synergy icon choices now display SVG icons only. Icon names remain available as accessible tooltips/labels and the existing form value is preserved.
- Rule-editor dropdowns have button-like styling, matching the hero picker controls.
- Synergy rule names are larger; COMMUNITY / OFFICIAL labels are smaller and aligned to the far right.
- The target/second side of Group Counter Rules is right-aligned.
- EDIT and VIEW GROUP controls have a small additional left inset.

## Deadpool role variants
- Replaced the Multi-role Deadpool roster entry with Deadpool V (Vanguard), Deadpool D (Duelist), and Deadpool S (Strategist/Support).
- All three variants use the same Deadpool artwork and ability kit, while role selection, labels and filtering use the selected role variant.
- Legacy saved entries named simply `Deadpool` are migrated to `Deadpool D` when records are normalized, preserving existing user data.

## Playbook toolbar
- Reduced preset colors to white, red, yellow and blue. The custom color picker remains available.
- Improved spacing and centered icons within Type buttons and color controls.

## Backend and deployment
- No Supabase schema, credentials, policies or data were changed.
- No live Vercel deployment was performed.
- V13.8 remains the untouched fallback package.

## Validation notes
- JavaScript syntax, CSS parsing, JSON validation and ZIP integrity are checked during packaging.
- Live browser interaction and production-host image loading still require a Vercel Preview test.
