# RIVALSNOTEBOOK V13.12 Release Notes

## Changes

### Playbook tool controls
- Type buttons are arranged below the TYPE heading in a spaced two-column grid.
- Color swatches are arranged below the COLOR heading with consistent spacing and centered controls.

### Text tool
- Text placement is intercepted before legacy Select/Move handlers. Clicking the Text tool arms placement; clicking a blank board location opens the inline rectangle editor and focuses it immediately.
- Text placement is cancelled with Escape. Existing text can still be edited by double-clicking it.

### Map views and saved strategies
- A, B, C and 2D boards are stored independently for each map and saved play.
- Older saved plays are migrated into their previously selected map/view to preserve existing objects.
- Selecting a new map defaults to Point A when that view exists.
- Switching map views snapshots the outgoing set and restores the destination set.
- Saved Plays use a visual menu with map-cover thumbnails, saved-view labels, and a checkered fallback for plays without a cover.

### Hero placement
- Added an ENEMY toggle beside the Vanguard/Duelist/Strategist filters. New heroes placed while it is active are tagged as enemies and receive a red border.
- Clicking the hero roster uses safe, evenly spaced default positions across the board.
- Hero and skill drag-and-drop uses transformed board-stage coordinates and intercepts the final drop event to avoid legacy duplicate handlers.

## Validation
- 24 inline JavaScript blocks passed `node --check`.
- 2 external JavaScript files passed `node --check`.
- 36 embedded CSS blocks and the external stylesheet parsed without errors.
- All 4 JSON files parsed successfully.
- ZIP integrity check passed.
- Browser interaction testing was not completed because this runtime blocks Chromium navigation to local files and localhost. GitHub, Vercel Preview and production interaction testing remain outstanding.
- No live Supabase database or production deployment was modified.
