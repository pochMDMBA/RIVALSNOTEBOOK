# RIVALSNOTEBOOK V13.20 Release Notes

Baseline: V13.19. This release contains focused refinements to the Playbook text controls and pen arrowheads.

## Changes

### No Fill and No Border icons
- Replaced the text labels in the NO FILL and NO BORDER action buttons with the original V13.18 icon artwork.
- NO FILL uses a white filled rectangle with a red diagonal slash.
- NO BORDER uses a border-only rectangle with a red diagonal slash.
- Kept the existing checkbox state, selected-state styling, saved settings, and toggle behavior.

### Font size stepper
- Reduced the numeric input's minimum width and compacted the +/- buttons.
- Kept the value centered and fully visible.
- Reserved fixed space for both controls so the plus button remains in view in the narrow Playbook sidebar.
- Kept the PX label hidden.

### Arrowheads
- Increased arrowhead length and width to give it more visual weight relative to the line.
- Retained the existing vector geometry that positions the line endpoint at the midpoint of the triangle base.
- Kept the connector stroke and triangle rendered in the same color and stroke context.

## Validation
- JavaScript syntax checks, JSON parsing, CSS parsing, local asset-reference checks, and ZIP integrity checks are performed for this package.
- Live Vercel deployment testing is not included.
