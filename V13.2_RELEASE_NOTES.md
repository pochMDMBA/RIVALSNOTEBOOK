# RIVALSNOTEBOOK V13.2 Release Notes

## Synergies and Counterpicker layout

- Fixed the page visibility conflict that could leave Counterpicker visible above Synergies. The workspace grid styles had higher specificity than the shared `.hidden` class, causing both pages to appear at once.
- Counterpicker and Synergies now share the same two-column panel geometry. Counterpicker keeps its Enemy Team roster and counter recommendations; Synergies keeps its Allied Hero roster and teammate recommendations only.
- Removed the excess vertical reservation around the Allied Team lineup so the Synergies results panel uses the available height consistently with Counterpicker.
- Preserved the separate Allied roster, lineup, clear action, community synergy library, and official Team-Up library.

## Tactical board selection

- Strengthened the yellow selection outline and glow for every selected board object, including multi-selected objects.
- Restored a visible yellow frame around icon-only hero tokens, which previously explicitly suppressed their selected outline.
- Added a yellow frame directly around skill artwork for selected ability tokens, including icon-only skill tokens.
- Selection rendering remains driven by the existing multi-selection state, so shapes, hero tokens, skill tokens, text, arrows, and other board objects continue to use the same selection logic.

## Validation

- JavaScript syntax validation: passed.
- CSS parsing validation: passed.
- JSON metadata validation: passed.
- ZIP integrity validation: passed.
- Existing Supabase schema/configuration and Vercel configuration were preserved.

A live Supabase-backed session and end-to-end browser interaction test were not performed as part of this package build. Deploy as a Vercel Preview first and verify both tabs and multi-selection before promoting to production.
