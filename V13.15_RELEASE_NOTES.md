# RIVALSNOTEBOOK V13.15

Based on V13.14. This is a focused layout and usability update.

## Changes

- Constrained the SAVE AS / SAVE / NEW action group to a three-column, width-bounded layout so Save As remains inside the top controls on desktop and narrow screens.
- Renamed the text-box color controls to **FILL**, **BORDER**, and **TEXT**. Each label stays on one line, with compact color inputs inside its own column.
- Reduced the vertical gap between the Playbook heading and the tool buttons.
- Removed the explanatory helper sentence under **Recommended Synergies**.
- Reworked the Synergies results panel into explicit rows for Allied Team, compact hero slots, the scrollable recommendation area, and footer. The Recommended Synergies heading remains visible at the top of its results area instead of being obscured by the hero slots.
- Kept the existing Supabase schema, Vercel settings, point images, board logic, saved plays, and all other features from V13.14.

## Validation

Static HTML/JavaScript/CSS and package integrity checks were run. A live hosted browser interaction test was not performed. Use a Vercel Preview deployment before production.
