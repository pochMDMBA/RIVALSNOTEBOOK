# RIVALSNOTEBOOK v13.33 Release Notes

Built from the v13.32 deployment package.

## Number markers
- Restored resizing for the compact circular number marker.
- Marker diameter and number font size now grow and shrink proportionally.
- Kept marker styling independent of the Text tool and made the resize handle accessible outside the marker's circular edge.

## Shapes and drawing controls
- New shapes default to 0% fill opacity, with the existing border opacity behavior retained.
- Replaced the numeric thickness readout with a percentage slider; 40% is the default (4.8 px on the 12 px scale).
- Reduced the default dimensions for newly created tactical shapes.
- Removed Area / Zone, Cone / Direction and Triangle Marker buttons.
- Reordered the shape palette so Circle, Rectangle, Triangle, Diamond and Star occupy the first row. The second row ends with Pin.
- Older saved shape types and their saved dimensions remain supported.

## Text boxes
- Added a dedicated text-box fill-opacity slider immediately above Font Size.
- The slider applies to selected text boxes and becomes the default for newly created text boxes. Existing text-box opacity is preserved.

## Pocket Strat
- Adds the two hero icons together near the centre of the currently edited Playbook.
- Checks existing board-object bounds and selects a nearby free pair of positions to avoid overlap.
- Preserves the active saved play and all existing board objects. No connector arrow or separate saved play is created.

## Preserved
- v13.32 number-marker appearance and double-click editing, except that number markers can now be resized.
- v13.31 map-set isolation, saved-play picker and text editing behavior.
- All map assets, embedded image fallbacks, Supabase configuration/schema and Vercel configuration.

## Validation
- JavaScript syntax checks passed for the cloud integration and v13.33 Playbook patch.
- All 33 executable inline scripts, 51 inline stylesheets, four JSON files, and the deployment ZIP passed static validation.
- The 63 bundled map images were checked against the map metadata.
- Full interactive checks in the hosted browser are still recommended for pointer resizing, slider behavior and Pocket Strat placement.
