# RIVALSNOTEBOOK v13.30 Release Notes

Built from the v13.29 deployment package.

## Saved-play map-set isolation

- Each Saved Play now belongs to exactly one tactical map.
- Standard maps retain their A, B, C and 2D board views within the same saved play.
- Competitive Domination maps retain their 1 + 2D, 2 + 2D, and 3 + 2D view pairs within the same saved play.
- Switching to a different map while a saved play is active prompts **Start a new play?**. Confirming first captures the current board set in the existing play, then opens a fresh play on the selected map. Cancelling leaves the current map and play unchanged.
- First-save and Save As flows now copy only draft boards belonging to the selected map. Legacy multi-map board data is reduced to the saved play's owning map.
- Submap 2D view keys are normalized consistently (`1-2d`, `2-2d`, `3-2d`) so save/load and Saved Plays view summaries agree.

## Saved-play cover thumbnails

- Saved-play picker thumbnails now resolve their image through `RN_MAP_COVER_IMAGES`, the same embedded JPEG registry used by the map library.
- This avoids relying on relative `assets/maps/covers/...` paths that can resolve incorrectly on nested Vercel routes.
- Museum cover fallback remains supported.

## Textbox editing

- Double-click interception now runs at window capture before board drag and selection handlers.
- Existing text boxes and number markers can be reopened for editing with double-click in Select/Move or Text mode.
- Text-tool single-click editing remains available.
- The editing surface is explicitly marked as a textbox and focused when opened.

## Preserved

- Existing six clean Competitive Domination cover images and all 18 Domination 2D layout references.
- Existing tactical map assets, hero/skill assets, board objects, Supabase configuration/schema, Vercel configuration and existing saved-play data format.
- No database migration is required.

## Validation

- JavaScript syntax checks for all inline and external scripts.
- CSS parsing and JSON parsing.
- ZIP integrity check.
- Cover registry keys and saved-play image resolution checks.
- Map-set isolation assertions for standard and Domination view-key formats.

A live browser interaction test and GitHub/Vercel deployment test have not been performed in this build environment.
