# RIVALSNOTEBOOK V13.21

## Changes

### Accurate board placement
- Removed the old inset clamp from hero and skill drag-and-drop. Pointer coordinates are calculated against the transformed board stage, so the drop point accounts for pan and zoom without a hidden safe area.
- Click-to-add heroes use a 4-column by 5-row formation on each side. Slot centers are adjusted using the live rendered hero-card dimensions so the full icon remains inside the board, including later placements.

### ENEMY modifier
- E now modifies selected hero and skill icons, including already-placed icons.
- While enabled, clicking an existing hero or skill icon changes it to the enemy side without disabling normal selection or movement.
- New and dropped hero/skill icons inherit the active enemy side. Both hero and ability renderers retain the red enemy treatment after redraw and reload.

### Arrowheads
- Arrow direction is calculated over a trailing look-back segment to ignore tiny end-of-stroke pointer jitter.
- Pen objects now expand their saved SVG bounds to include the arrowhead base corners, preventing clipping on very thin horizontal or vertical strokes.
- Arrowheads are longer than wide. Solid shafts terminate at the center of the arrowhead base; dashed arrows receive only a short tangent-aligned solid tail to guarantee the base connection.

## Validation
- JavaScript syntax, CSS parsing, JSON, map asset-reference, and ZIP integrity checks are performed.
- No live Vercel deployment or production Supabase changes are made.
- Live browser interaction testing is not claimed unless separately observed.
