# RIVALSNOTEBOOK V13.14 Release Notes

Built from V13.13. This release focuses on Playbook toolbar sizing, enemy placement control, save confirmations, and persistent editable text boxes.

## Changes

- Resized Fill Color, Border Color, and Text Color controls so each picker stays within its own card in the narrow Playbook sidebar.
- Changed the Freehand Pen swatch layout to a three-column grid with fixed, non-overlapping swatch dimensions.
- Restored the ALL / V / D / S role filter buttons and replaced the worded Enemy control with a circular **E** button immediately to the right of S. The E button lights red while enemy placement is enabled.
- Grouped **SAVE AS**, **SAVE**, and **NEW** in the Playbook top bar. Save, New, and Delete now use a themed in-app confirmation dialog. Save As creates a separate copy and carries over saved map/view board sets.
- Reworked text-box editing persistence. Text is saved as a text object, keeps its fill/border/text colors and opacity, and remains editable by double-clicking after saving or reloading a play. Text input is autosaved while typing and committed on blur or Ctrl/Cmd+Enter.

## Preserved

- Existing map library and Point A/B/C JPEG assets.
- Existing A/B/C/2D board separation and saved play board sets.
- Supabase schema, credentials/configuration, and Vercel configuration.

## Validation

Static JavaScript syntax checks, CSS parsing, JSON validation, asset-reference checks, and ZIP integrity checks are performed for this package. Live Vercel and authenticated Supabase interaction testing is not included.
