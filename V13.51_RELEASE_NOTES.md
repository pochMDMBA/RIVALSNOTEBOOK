# RIVALSNOTEBOOK v13.51 Release Notes

## Active tab visibility
- Increased contrast, brightness, border emphasis and glow for the active main navigation tab and active roster tab.

## Counterpicker matchup layout
- Moved the `VS + hero portrait + hero name` identity to the right edge of each matchup row, overriding the older left-aligned layout rule.
- Removed the empty `<details>` wrapper after extracting its matchup list. This prevents the browser's default “Details” label from appearing.

## Matchup scoring
- Counter Pick totals now count only the highest-scoring entry for each counter-hero versus enemy-hero matchup. Multiple reasons or rules for the same matchup no longer stack.
- Counter scores against different enemy heroes still add together, and Counter Pick ordering uses the corrected aggregate.
- Synergy suggestion totals now count only the highest-scoring entry for each suggested-hero and teammate pairing. Different teammate pairings still add together.
- Synergy suggestion cards are re-sorted using the corrected aggregate totals.
- Existing strength, official Team-Up and vote point values are retained.

## Cache and release
- Updated the application title and package version to v13.51.
- Bumped the runtime script cache keys and UI patch guard to v13.51.

No Supabase migration is required. Existing workspace data, votes, comments, maps and Playbook records retain their existing formats.
