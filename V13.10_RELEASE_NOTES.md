# RIVALSNOTEBOOK V13.10 Release Notes

## Point-image deployment fix
- Diagnosed the repeated Point A/B/C loading failure: all 18 JPEGs existed and decoded correctly in the V13.9 ZIP, but they were referenced from the additional nested `assets/maps/points/` directory.
- Moved all 18 point JPEGs into the same established `assets/maps/` directory as the already-working map overview images.
- Updated the map metadata in `index.html` and `map-library.json` to use `/assets/maps/<map>-point-<a|b|c>.jpg`.
- Removed the redundant nested point-image directory.
- Updated asset diagnostics to recognize both root-relative and relative local map paths and changed the cache-busting token.

## Map-view selector
- Changed the selector to one full-width 2D button on the first row, followed by three equal-width A, B and C buttons on the second row.
- Shortened the point labels to A, B and C so they remain centered and fully inside their borders.

## Hero Group cards
- Moved EDIT, VIEW GROUP and SUBMIT TO COMMUNITY into a single bottom action row.
- Changed group cards to stretch as flex columns and pushed the action row to the card bottom, keeping the delete X at the top-right.
- Kept the submit action smaller, with compact wrapping on narrow cards.

## Preserved
- Supabase schema and configuration.
- Vercel configuration.
- Existing map covers, 2D maps, hero data, counters, synergies and saved-play logic.
- V13.9 retained as a fallback package.

## Validation
- 18 point JPEGs copied and byte-validated.
- All map point references updated in inline metadata and `map-library.json`.
- JavaScript syntax and JSON validation performed during packaging.
- ZIP integrity check performed.
- Live Vercel/browser interaction testing remains necessary to confirm deployment from the user's repository.
