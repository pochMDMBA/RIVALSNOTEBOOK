# RIVALSNOTEBOOK v13.47 Release Notes

## Synergies scrolling layout

- Removed sticky positioning from the Recommended Synergies heading and its adjacent Show Only Upvoted Synergies / Add Synergy controls.
- The full toolbar now occupies normal document flow above the suggestion cards and scrolls with them, preventing it from floating over recommendation content.
- Kept the filter and Add Synergy button together on the right side of the heading row.

## Counterpicker matchup rows

- Forced `VS`, the target hero portrait and hero name into one horizontal, right-aligned row.
- Removed the decorative `GROUP RULE` badge from Counterpicker matchup targets.
- Kept generated group-rule matching, voting, editing and source attribution behavior intact.

No changes were made to Synergies data, Group Synergy Rules, Playbook features or Supabase configuration.
