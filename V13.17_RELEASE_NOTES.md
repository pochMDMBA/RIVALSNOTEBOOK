# RIVALSNOTEBOOK V13.17 Release Notes

## Playbook drawing and toolbar fixes

- Dashed and solid freehand arrows now use a dedicated solid connector from the final shaft segment to the exact midpoint of the triangular arrowhead base. The same connector geometry is used in the live drawing preview and in the saved SVG rendering. This prevents a dash gap from visually separating the shaft from the arrowhead.
- Removed the Eraser button from the primary Playbook toolbar. The primary tool row now contains Select/Move, Freehand Pen, Text, and Image.
- The inactive Freehand Pen button now uses the same background and border treatment as the other primary buttons. Its active state continues to use the shared active-tool styling.
- Reworked the FONT SIZE control into a two-row layout: label above, then minus / number / plus / PX controls. The number input expands into the available width so its border no longer overlaps adjacent controls in the narrow sidebar.
- Reduced the vertical gap between the Tools heading, its subtitle, and the tool buttons.
