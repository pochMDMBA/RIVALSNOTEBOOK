# RIVALSNOTEBOOK v13.25

## Fixes

### Museum of Contemplation cover on GitHub/Vercel
- Rebuilt `assets/maps/covers/museum-of-contemplation.jpg` from the latest user-provided image.
- Embedded the JPEG as a data-URL fallback in the existing `RN_POINT_MAP_IMAGES` asset registry so the map library card and current-map cover loader do not depend solely on a deployment-relative path.
- Saved-play thumbnails use the same embedded cover fallback.

### Board mouse interaction
- Removed left-button and Alt+left-button panning. Left-button drags over empty board space initiate marquee selection again.
- Retained middle-button (scroll-wheel click) pan/drag.

### Ctrl+A
- Added a window-capture shortcut handler for Ctrl+A / Cmd+A while Playbook tools are active.
- Native select-all remains available inside text editors and normal form inputs.

### Textbox persistence
- The board pointer-up handler redraws only when an actual board gesture was active.
- Text placement no longer triggers an unrelated redraw that detaches the inline editor after mouse release.

## Validation
- Verified JPEG structure and decoded the cover image.
- Confirmed the embedded cover fallback matches the packaged image bytes in the v13.25 package.
- JavaScript syntax, CSS parsing, JSON parsing, local map asset references, and ZIP integrity were checked.
