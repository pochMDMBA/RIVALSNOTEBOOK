# RIVALSNOTEBOOK v13.54 Release Notes

## Synergy ranking and controls
- Sorted the condensed suggested-hero cards by their combined contribution points, highest first. A suggestion with 200 total points now ranks above suggestions with 100.
- Kept per-pair contribution scores and the official Team-Up label while sorting the aggregate hero cards.
- Fixed Synergy HIDE ALL / SHOW ALL to control each suggested-hero list.
- Preserved individual SHOW / HIDE controls after a bulk action. Individual choices remain in effect while the bulk control continues to apply to other cards.
- Added delegated edit routing for condensed Synergy entries so EDIT opens the matching individual synergy or Group Synergy Rule.

## Add forms and Groups
- Enabled Hero / Hero Group selectors in Add Counterpick and Add Synergy, not only in the Groups page.
- Choosing a group on either side creates the corresponding Group Counter or Group Synergy Rule.
- Group Rules still require at least one Hero Group; individual Hero : Hero entries remain normal Counter Picks or Synergies.

## Labels, attribution and typography
- Removed Hard / Moderate / Soft Counter and Strong / Moderate / Situational badges from the recommendation cards without changing scoring.
- Retained those tier names and point values in the Add forms.
- Moved Counterpicker's submitted-by attribution below the matchup details.
- Matched Synergy description font to Counterpicker typography while retaining its existing text size.
- Matched Counterpicker description text size to Synergy while preserving its font.

## Cache and release
- Updated the app title and package version to v13.54.
- Bumped runtime cache keys and the UI helper guard to v13.54.

No Supabase migration is required. Existing groups, rules, synergies, counters, votes, comments, maps and Playbook records retain their existing formats.
