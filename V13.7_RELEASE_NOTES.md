# RIVALSNOTEBOOK v13.7 release notes

## Tactical map library

- Added Lower Manhattan to the Convergence map pool, with a hosted map cover and all three user-supplied point screenshots.
- Added Point A, Point B and Point C views for the six supplied Convergence maps:
  - Central Park (Dracula screenshots)
  - Hall of Djalia (HALL OF DJALIA / HALL screenshots)
  - Symbiotic Surface (Klyntar screenshots)
  - Heart of Heaven (Kunlun screenshots)
  - Shin-Shibuya (SHIN SHIBUYA / SHIN screenshots)
  - Lower Manhattan (Lower Manhattan screenshots)
- Existing overview map images remain the 2D views. Point screenshots are stored as individual WebP assets under `assets/maps/points/`.
- The Lower Manhattan full 2D overview is not included in this build because a verified, usable top-down overview asset could not be located. Its 2D option is disabled with an explanatory notice; Points A/B/C remain selectable.
- Selected map and point view continue to be saved to the active play and browser storage.

## Hero Groups and group rules

- Removed the group-member multiplication/count line from group-counter rule cards, including the expanded side counts.
- Group Counter Rules help text now describes the reusable rule and its member details without showing generated matchup totals.
- Group selectors display the actual vector icon and group name. Internal icon identifiers are not exposed as labels.
- The Individual Heroes selector is partitioned by role and uses title-case role labels. The Group Editor headings now use title case as well.
- Removed the generic “Custom Hero Group” placeholder description from existing group cards when present.
- Kept the group-card layout with the delete X at the top-right, Edit directly below the group name, and a compact Submit to Community action at the lower-right.

## Backend and deployment

- Based on V13.6.
- Front-end and static asset changes only. No Supabase schema or credentials were changed.
- Vercel configuration was preserved.
- Live browser interaction testing and production deployment were not performed. Use a Vercel Preview deployment before promoting this package.
