# RIVALSNOTEBOOK v13.37 Release Notes

Built from the v13.36 deployment package.

## Group Synergy Rules
- A Group Synergy Rule can only be saved when at least one side is a Hero Group.
- Two individual heroes remain regular Synergies and cannot be saved into Group Synergy Rules.
- The form displays the group-side requirement and blocks invalid Group Rule submissions before the existing save handler runs.

## Pocket Strat action
- Renamed the card action from **PLAY** to **SEE PLAY**.
- Positioned the action at the far right of the action row.

## Reddit-style account voting
- Replaced the single upvote pill with a vertical upvote, net score and downvote stack.
- Each account can have one direction per item: upvote, downvote or no vote.
- Clicking the same direction again removes the vote; choosing the opposite direction changes it.
- Upvote/downvote state is loaded from the signed-in account. Voting while logged out opens the existing sign-in / sign-up modal.
- The aggregate score is net upvotes minus downvotes and can be negative.
- The app remains compatible with existing upvote-only rows until the supplied Supabase migration is applied; downvotes prompt for the migration when it is missing.

## Personal filters
- Added **Show Only Upvoted Synergies** and **Show Only Upvoted Counter Picks** checkboxes.
- Each filter shows only items the signed-in account has positively upvoted.
- Signed-out users are prompted to sign in or create an account when enabling either filter.
- Filters reset when the account signs out.

## Required Supabase migration
Run `supabase/migrations/20261126_community_vote_directions.sql` in the SQL Editor of the Supabase project configured in `config.js`. The migration adds a per-account vote direction, allows negative aggregate scores and updates the aggregate trigger. Existing vote rows are preserved as upvotes. The updated base `supabase/schema.sql` includes the same structure for new installations.

## Preserved
- v13.36 Synergies layout reversion, proportional pen arrowheads, Pocket Strat workflow, Saved Play discard confirmation, marker resizing, and shape/text controls.
- Existing Supabase workspace, notebook, group and map data. The migration does not delete existing user votes.

## Validation
- Static JavaScript and SQL checks passed.
- Live browser click testing and Supabase migration execution remain required after deployment.
