# RIVALSNOTEBOOK v13.1 release notes

## Groups tab

- Removed the duplicate red group-delete overlay. Each group card now has one plain, larger X delete control in its action row. The existing delete confirmation and state cleanup remain in place.
- Applicable Group Synergy Rules in the group detail view now show the related group-level rule and its description, rather than expanding the relationship into individual hero-to-hero pairings.
- Selecting an applicable group synergy closes the group detail overlay, opens and scrolls to the corresponding rule in the Group Synergy Rules list, and highlights that rule. Keyboard activation with Enter or Space is supported.
- Increased the description text size in the applicable group synergy detail view.

## Synergies tab

- Clarified the roster heading as **Allied hero roster**. The page remains limited to allied hero selection and synergy recommendations; the Enemy Team roster and Counterpicker recommendations remain on the Counterpicker page.
- Increased the description text size on synergy recommendation cards for readability.

## Preservation and validation

- Built on the recovered V13 package. No Supabase schema, credentials, Vercel configuration, tactical map assets, or external service settings were changed.
- No database migration is required.
- JavaScript syntax checks passed for every inline script, `rivalsnotebook.js`, and `config.js`.
- HTML duplicate-ID checks, JSON checks, map asset checks, and ZIP integrity checks passed.
- A live browser interaction test could not be completed in this environment. Please use a Vercel Preview deployment to verify delete confirmation, rule navigation/highlighting, and responsive layout before promoting to production.
