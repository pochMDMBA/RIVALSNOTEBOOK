# RIVALSNOTEBOOK V13.22

## Changes

### Group cards
- Lowered the group-name label slightly so it aligns more closely with the vertical center of the group icon.

### Playbook placement
- Corrected new hero token positioning by ensuring hero board items use absolute positioning inside the transformed board stage. Their measured center now uses the same coordinate anchor as skill tokens and existing board elements.

### Number markers
- Number markers now open in the text editor when added from the tactical palette and when dropped onto the board.
- Existing number markers can be edited by double-clicking them.
- Number markers now support the shared text fill, border, text color, font size, bold, no-fill, and no-border controls.
- The original sequential number value remains stored separately, so adding new markers continues the existing numbering sequence even when the displayed text is changed.
- Number marker text and styling are included in normal board persistence and saved plays.

### PIT / HAZARD tool
- Removed the PIT / HAZARD palette action and legacy PIT button. Existing saved PIT objects remain compatible with old board data.

## Validation
- JavaScript syntax checks for all inline scripts.
- CSS parsing, JSON parsing, and deployment ZIP integrity checks.
- Static checks for expected marker controls, preserved number sequence fields, removed PIT palette actions, and the hero positioning override.
- No live Vercel deployment or production Supabase changes were made.
- Live browser drag-and-drop interaction testing was not performed in this environment.
