# RIVALSNOTEBOOK v13.32 Release Notes

Built from v13.31.

## Number marker restoration
- Restored the compact original 31px yellow circle with a centered number.
- Number markers use their own fixed style and no longer inherit the general Text tool's DEFAULTS or text-box fill/border controls.
- Removed internal scrollbars and resize behavior from number markers and their inline editor.
- Creating a number marker no longer immediately opens a large text editor; double-click editing remains available.

## Pocket Strat workflow
- Pocket Strat actions are available on synergy cards, including group-generated synergy pairs, and individual counterpick/group-counter matchup reasons.
- Clicking Pocket Strat adds the two associated heroes to the currently edited Playbook at the lower-left of the board.
- Both new hero objects are selected together for immediate repositioning.
- Existing board objects, active saved-play ID, and play name are preserved.
- No straight arrow, note, new draft play, or automatic save is created. The current Playbook can be saved normally when ready.

## Preserved
- v13.31 saved-play map-set isolation and confirmation behavior.
- Embedded Domination covers, the independent tactical-map registry, and existing map assets.
- Supabase configuration/schema and Vercel configuration.

## Validation
- Static JavaScript syntax, CSS parsing, JSON parsing, package asset references and ZIP integrity checked.
- Live browser interaction testing is still required for pointer selection, multi-select, Pocket Strat placement and manual Save behavior.
- No GitHub push, Supabase mutation or Vercel deployment was performed.
