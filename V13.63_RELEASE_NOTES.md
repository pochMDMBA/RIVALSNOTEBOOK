# RIVALSNOTEBOOK v13.63 Release Notes

## Recommendation data cleanup
- Removed all non-user-authored bundled counter recommendations and ordinary synergy pairings, including records based on Reddit, other websites and generated research hypotheses.
- Retained the 28 player-submitted counter entries from v13.5.
- Retained user-authored counter and synergy records identified by submitter attribution or the existing custom-record conventions.
- Preserved Official Team-Ups and all Group Synergy Rules and Group Counter Rules.
- Added a runtime cleanup so imported reference records already present in local or account-saved workspaces are filtered out after workspace loading and do not return after refresh.
- No Supabase schema migration is required.

## Counterpicker attribution
- Moved **Submitted by [Username]** to the bottom of each user-authored Counterpicker entry.
- User-authored entries no longer display a generic content-source label in place of the submitter.
- Source-only records use **Source: [Source]**, without incorrectly presenting the source as a submitter.

## Release
- Updated the application package to v13.63.
