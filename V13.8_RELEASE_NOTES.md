# RIVALSNOTEBOOK V13.8 Release Notes

Built from V13.7. This release contains the following changes:

## Map point assets
- Converted all 18 supplied Convergence Point A/B/C map images to optimized JPEG files.
- Updated the map registry and fallback references to `.jpg` paths.
- Removed the old `.webp` files from `assets/maps/points/`.

## Group Counter Rules
- Removed expanded hero-by-hero matchup lists from the Group view.
- Each applicable Group Counter Rule now appears once with a `VIEW RULE` button.
- `VIEW RULE` closes the group detail window, scrolls to the matching rule in the Group Counter Rules manager, opens it when expandable, and briefly highlights it.
- Increased Group Counter Rule title sizes in the group view and main rules list.

## Counterpicker hero selection
- The image-based, role-grouped Select Hero picker is now shown for direct Add Counterpick flows as well as Group Counter Rule editing.
- Native select fields remain synchronized for existing application logic, and fields hidden by the current form mode remain hidden.

## Playbook
- Type buttons and color swatches have larger hit targets.
- Removed the hidden 8px edge clamp applied during rendering and placement.
- Removed position clamping when adding, dropping, moving, resizing, or reloading board items.
- Stage-relative, zoom-aware placement is used across map views so items follow the pointer consistently.
- Pen preview and saved paths use the same captured color, width, opacity, dash style, and line caps. The freehand stroke now uses a butt cap to avoid a brush-like rounded finish.
- Reduced the minimum pen path bounds to approximately one screen pixel for straight or near-straight strokes.

## Validation
- JavaScript syntax checked with Node.js.
- JSON files parsed successfully.
- CSS parsed where the CSS parser is available.
- All 18 JPEG point assets and all local references verified.
- ZIP integrity checked.

Live Vercel/Supabase browser interaction testing has not been completed. Deploy as a Preview first. No live database or production deployment was modified.
